# FastAPI Prototype Projects

This directory contains prototype projects created during the development process of the Library API v7 project.

These prototypes were used to explore and test different backend concepts before combining them into the final Library API implementation.

## Projects

### Shop API

A prototype API created to experiment with product/shop related CRUD operations.

Concepts explored:

- FastAPI routing
- Request validation
- API structure
- Database operations


### Users API

An early authentication prototype focused on user management.

Concepts explored:

- User creation
- Password handling
- Database models
- Authentication flow


### Users V2 API

An improved version of the users prototype with more advanced authentication features.

Concepts explored:

- JWT authentication
- Secure password hashing
- User sessions
- Authorization concepts


## Purpose

These prototypes served as stepping stones toward building Library API v7, which combines authentication, user ownership, CRUD operations, validation, and database recovery into a complete backend application.
